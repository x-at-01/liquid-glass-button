Liquid Glass-knop

Een Liquid Glass-knop die met het label meegroeit, met echte randbreking.

Beweeg eroverheen.

De breedte komt van de tekst

Hoe langer het label, hoe breder de knop — de ronding aan de uiteinden blijft gelijk.

Op licht vlak oogt het glas bleek; de tint houdt de tekst leesbaar.

Hoe de SVG werkt

Het vloeibare gevoel komt van de rand: een verplaatsingskaart wordt op exacte grootte gemaakt, drie passes zorgen voor dispersie en een randmasker houdt het midden scherp.

01

Verplaatsingskaart: op exacte knopgrootte gemaakt — R bevat de x-verplaatsing, G de y-verplaatsing, B de randsterkte (0 in het midden, 255 aan de rand).

02

Dispersie: drie passes over dezelfde kaart met iets verschillende schalen; de R/G/B-kanalen worden gesplitst en met screen samengevoegd, waardoor de rand als echt glas uiteenvalt.

03

Randmasker: het B-kanaal maskeert het resultaat — alleen de rand breekt, het midden onder het label blijft onaangetast.

/* 1) 按按钮实际尺寸生成位移图（app.js → canvas） */
R = 128 + x 位移 · G = 128 + y 位移 · B = 边缘强度（中心 0 → 贴边 255）

/* 2) 同一张图做三次位移，scale 略有差异，分离 R/G/B 后 screen 叠加 → 色散 */
feDisplacementMap  in2="map"  scale="s·1.00"  → feColorMatrix → R
feDisplacementMap  in2="map"  scale="s·0.92"  → feColorMatrix → G
feDisplacementMap  in2="map"  scale="s·0.84"  → feColorMatrix → B
feBlend mode="screen"

/* 3) 用位移图的 B 通道做遮罩：只有边缘参与折射，中心保持清晰 */
feComponentTransfer → edgeMask
feComposite in="edge" in2="center" operator="over"

/* 4) 背景模糊链（SVG 滤镜只负责折射，磨砂交给 blur） */
backdrop-filter: url(#glass-N) blur(6px) contrast(1.15) saturate(170%)

Gebruik

Eén element is het hele glas: vorm, rand en diepte zijn verlopen en schaduwen; de randbreking komt van een filter dat op exacte grootte is gemaakt.

.btn {
  display: inline-flex; align-items: center; gap: 9px;
  height: 56px; padding: 0 28px;            /* 宽度由文字决定 */
  border: 0; border-radius: 980px;
  background:
    radial-gradient(125% 112% at 50% -26%, #ffffff42, #ffffff14 30%, transparent 62%),
    linear-gradient(180deg, transparent 62%, #0000002e),
    var(--tint);                          /* 黑 rgba(12,12,14,.82) / 蓝 rgba(16,54,178,.82) */
  box-shadow: inset 0 -12px 16px -12px #ffffff1a,
              0 10px 22px -8px #00000052, 0 2px 6px #00000024;
  backdrop-filter: url(#glass-1) blur(6px) contrast(1.15) saturate(170%);
}
