Liquid Glass · 4× アセット

リキッドグラスボタン

Apple の Web タイポグラフィ基準（SF Pro、本文 17px、ボタン 56px）。幅は文字に追従し、素材は 4× 、中央は無限にタイル可能。

幅は文字で決まる

width は指定しません。同じ3分割アセットで、文字が長いほどボタンが広がり、端の丸みは変わりません。

3分割アセット（4×）

素材は高さ 224px（4×、表示は 56px）。端は各 112px、中央タイルは 128px、継ぎ目はピクセル単位で一致。

中央タイル · repeat-x · どんな幅でも歪まない

使い方

1つの要素で九宮格の伸縮を実現。hover / active で SVG フィルタを切り替えます。

.btn {
  display: inline-flex; align-items: center; gap: 9px;
  height: 56px; width: auto;              /* 宽度由文字决定 */
  border: 0 solid transparent;
  border-left-width: 28px; border-right-width: 28px;
  border-image: url(./assets/glass/black-sheet.webp) 0 112 0 112 fill stretch;
  border-radius: 980px; color: #fff;
  backdrop-filter: url(#glass-1) blur(6px) contrast(1.15) saturate(170%);
}
/* 位移图 + 滤镜模板都在 ./assets/glass-filters.svg */

仕様

書体

SF Pro Display / SF Pro Text。本文 17px/1.47、字間 -0.022em、見出し 48px/1.08。

ボタン

高さ 56px（モバイル 48px）、左右 28px、角丸 980px、アイコン 20px。

素材

4×：高さ 224px、端 112px、タイル 128px。可逆 WebP で透過を保持。

アイコン

24px の SVG を SVGO で圧縮し、20px で表示。

マテリアルは Qwen-Image-2.1（ネイティブ alpha）で生成し、形状と光はプロシージャルなリキッドグラス描画で再構成。エッジの屈折は SVG feDisplacementMap。

Apple ロゴは Apple Inc. の商標で、App Store ボタンのレイアウトとアイコンの用法を示す目的にのみ使用しています。
