SVG nasıl çalışır

Sıvı hissi kenardan gelir: tam boyuta göre bir yer değiştirme haritası üretilir, üç geçiş dağılmayı oluşturur ve kenar maskesi merkezi net tutar.

01

Yer değiştirme haritası: düğmenin tam boyutunda üretilir — R x kaymasını, G y kaymasını, B kenar gücünü tutar (merkezde 0, kenarda 255).

02

Dağılma: aynı harita üzerinde biraz farklı ölçeklerle üç geçiş; R/G/B kanalları ayrılıp screen ile birleştirilir, kenar gerçek cam gibi dağılır.

03

Kenar maskesi: B kanalı sonucu maskeler — yalnızca kenar kırılır, etiketin altındaki merkez hiç etkilenmez.

/* 1) 按按钮实际尺寸生成位移图（app.js → canvas） */
R = 128 + x 位移 · G = 128 + y 位移 · B = 边缘强度（中心 0 → 贴边 255）

/* 2) 同一张图做三次位移，scale 略有差异，分离 R/G/B 后 screen 叠加 → 色散 */
feDisplacementMap  in2="map"  scale="s·1.00"  → feColorMatrix → R
feDisplacementMap  in2="map"  scale="s·0.92"  → feColorMatrix → G
feDisplacementMap  in2="map"  scale="s·0.84"  → feColorMatrix → B
feBlend mode="screen"

/* 3) 用位移图的 B 通道做遮罩：只有边缘参与折射，中心保持清晰 */
feComponentTransfer → edgeMask
feComposite in="edge" in2="center" operator="over"

/* 4) 背景模糊链（SVG 滤镜只负责折射，磨砂交给 blur） */
backdrop-filter: url(#glass-N) blur(6px) contrast(1.15) saturate(170%)

Kullanım

Tek bir öğe camın tamamı: biçim, kenar ve derinlik gradyanlar ve gölgeler; kenar kırılması tam boyuta göre üretilen filtreden gelir.

.btn {
  display: inline-flex; align-items: center; gap: 9px;
  height: 56px; padding: 0 28px;            /* 宽度由文字决定 */
  border: 0; border-radius: 980px;
  background:                               /* 扁平：几乎平色，只有极轻的顶缘受光 */
    radial-gradient(125% 112% at 50% -26%, #ffffff1f, #ffffff08 30%, transparent 55%),
    linear-gradient(180deg, transparent 66%, #0000001a),
    var(--tint);                          /* 黑：rgba(12,12,14,.82) */
  box-shadow: inset 0 1px 1px #ffffff2e,  /* 发丝级棱边 */
              inset 0 -1px 1px #00000033,
              inset 0 -10px 14px -12px #00000038;
}
.btn--blue {                              /* 蓝：竖向明度差约 6%，白字对比约 4.4:1 */
  background: linear-gradient(180deg, #125fd8 0%, #0746a4 100%);
  backdrop-filter: url(#glass-1) blur(6px) contrast(1.15) saturate(170%);
}
/* 天光：::after 径向柔光 + mix-blend-mode:screen（负 z-index，压在底色上、文字下） */
